Sign-in and editing help

  1. Sign in with a GitHub token (not “Sign in with GitHub,” unless OAuth is configured).
  2. Open Albums, choose the album, and expand the track you want to edit.
  3. Select the matching existing file in Timed lyrics file (.lrc or .vtt). Files already live under Albums/lyrics/; choose one instead of uploading a duplicate.
  4. For a new song, drop its .lrc or .vtt file onto the lyrics field. Use timestamps like [00:12.34] Hello there for synchronized karaoke.
  5. Publish your album, wait for GitHub Pages to update, then check the live lyrics.
Plain lyrics, sign-in and troubleshooting

Leave “Lyrics text” empty if the song uses a timed file. For unsynchronized lyrics, paste plain text there instead. Use “Sign In with Token” and a repository-limited GitHub access token with Contents read/write and Metadata read permissions. If a file is missing from the published checker, reopen the album and select the matching existing lyrics asset before publishing again.
