Your album library

Pages CMS edits the existing album files in data/albums/ and uploads audio, artwork, and lyrics into the existing Albums/ folders. The player and catalog pipeline stay unchanged.

Open Pages CMS ↗
  1. Sign in to Pages CMS with GitHub and open the Tyraxiss / Tyraxiss.github.io repository on the main branch.
  2. Choose Music Library to search albums by title, artist, or year. Open an album to edit its artwork and metadata or expand its ordered track list.
  3. Make changes in Pages CMS and wait for the repository workflow and GitHub Pages deployment to finish before checking the live player.

Lyrics and validation

Timed LRC, enhanced LRC, WebVTT, and SRT files belong in Albums/lyrics/. Use the lyrics tools page to preview a file before publishing and check the live linked files afterward.

Album JSON remains the source of truth for track order and lyrics links. The GitHub Actions pipeline continues to refresh durations from audio with FFmpeg, validate media paths, and test player playback and mobile layout.
