    The reliable lyrics workflow

    Changes are published through the existing GitHub-backed album editor. Keep the lyric file and its track linked in the album entry.

    1. 1. Select the fileOpen the album editor, choose The Last Of Me, expand a song, and select its matching .lrc or .vtt under Timed lyrics file.
    2. 2. Keep lyrics tidyLeave Lyrics text empty when a timed file is attached. Each synchronized LRC line starts with a timestamp, e.g. [00:12.34] words.
    3. 3. Publish the albumPublish the album and wait for GitHub Pages to update the public catalog and lyric assets.
    4. 4. Check the live siteReturn here and select Check linked lyrics; the report includes a direct link for each file that needs attention.

    Adding new songs: drop the audio into its album folder, add the track through the editor, then attach its timed lyric file. Lines must use timestamps such as [00:12.34] words. Existing reusable lyrics are in Albums/lyrics/.
