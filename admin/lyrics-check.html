Manage album JSON, ordered tracks, audio, artwork, and synchronized lyrics in Pages CMS. It edits the same repository files used by the player.

Check the live lyrics

Test the currently published catalog—not unsaved editor drafts. This checks that every linked lyric file loads and has synchronized LRC lines or WebVTT cues.

Select “Check linked lyrics” to test the public player’s files.

    Test a lyrics file before publishing

    Drop or choose an .lrc, enhanced .lrc, .vtt or .srt file. It runs through the exact parser the player uses, so this is what visitors will see: line timings, word timings for karaoke, and any lines that would show up untimed.

      The reliable lyrics workflow

      Changes are committed to the repository through Pages CMS. Keep the lyric file and its track linked in the album entry.

      1. 1. Select the fileOpen Pages CMS, choose The Last Of Me, expand a song, and select its matching .lrc or .vtt under Timed lyrics file.
      2. 2. Keep lyrics tidyLeave Lyrics text empty when a timed file is attached. LRC lines start with [00:12.34] words; enhanced LRC word tags <00:12.50>, WebVTT cues and SRT all work too.
      3. 3. Commit your changesSave the album changes in Pages CMS and wait for GitHub Actions and GitHub Pages to update the public catalog and lyric assets.
      4. 4. Check the live siteAfter deployment, return here and select Check linked lyrics; the report includes a direct link for each file that needs attention.

      Adding new songs: upload the audio into its album folder, add the track in Pages CMS, then attach its timed lyric file. Lines must use timestamps such as [00:12.34] words. Existing reusable lyrics are in Albums/lyrics/.
